## Earlier integration snapshot

Root owns routing, publication command integration, output and metadata hooks, configuration, and the shared CLI fixture. Repo creation and PR creation now use `preparePublication` and `executePublication`. Commit-to-PR calls the same PR workflow after the explicit local commit.

Root removed the publication service's duplicate PR transport in favor of `createPullRequest`. Native attachments preflight before repo mutation. Partial GitHub upload errors preserve the PR URL. Existing-PR attachment updates must use the explicit target host and repository.

JSON output now waits for command post-actions. Operation hooks create private metadata records for supported mutations and AI work, excluding dry-run, native escapes, and record inspection. The recording opt-out is `GGH_NO_RECORDS=1`. Tests that use broad inherited environment disable general history, while the isolated fixture clears that setting and tests the default.

The isolated CLI fixture intercepts GitHub and known provider processes. It supports seeded user config and direct service invocation, preserves native streams, and captures body input. Git config overrides are removed from its inherited environment. Source tests must not call live providers or accounts.

Stack recovery is in progress in a Luna worker. It owns only `src/commands/stack.ts`, `src/services/git/stack.ts`, and its new recovery test. It reuses the active operation record and keeps branch order and tips in a private Git metadata checkpoint.
