# Complaint coverage

The supplied Theo Browne analysis is product input. Its historical quotes and vendor claims were not independently verified. This map addresses the workflow complaints with source behavior and direct qualification. A receipt proves its recorded revision and scope, rather than every possible GitHub account or terminal.

| Concern | Implemented behavior | Evidence and limits |
| --- | --- | --- |
| Word deletion, queued input, cancellation | Buffered input preserves queued answers and supports word deletion. EOF/Ctrl-C cancels with exit 130. | Prompt tests and actual macOS/Linux native terminal checks. Windows ConPTY qualification is a required release gate. Keyboard layouts beyond those checks remain unqualified. |
| Repo wizard asks for known values | Infer Git root, folder name, private visibility, origin, and branch. One confirmation is the default; explicit flags and user settings support automation. | Publication tests and live private/public repo creation. Ambiguous bases and non-GitHub remotes require resolution. |
| Repeated remote/push setup | Repo creation, PR creation, and commit-to-PR share a publication plan, explicit approval snapshot, and revalidation. | Live private setup, push rejection, recovery and repeated-resume no-op; independent commit-to-PR journey. No invented commits or history rewriting to manufacture a base. |
| Long pauses | Local stack reads remain offline. Remote views use bounded concurrency. Optional status provider probes have a separate one-second subprocess budget. | Validated native benchmark fixtures and a controlled slow-provider reproduction. GitHub response latency remains outside the CLI's control. |
| Screenshots and videos in PRs | Detect native attachment support. Configured storage is an explicit public-target fallback; private evidence cannot use public storage. | Live private PNG upload matched authenticated bytes and returned 404 anonymously. Attachment format, size, count, capability, and partial-result tests remain. Large-video server acceptance was not qualified. |
| Stacked branches | Save parent relationships, restack locally with continue/abort and recovery tips, submit explicitly with exact PR head/base and force-with-lease. | An independent agent resolved a real conflict and submitted two live draft PRs with matching local/remote OIDs. Additional recovery, drift, and lease cases use local fixtures. |
| Manual PR drafting | Opt-in Git editor supports a first-line title and Markdown body. Private drafts survive decline or failure. User-selected files are preserved. | Actual vi edit, decline, reopen, partial upstream failure, and successful single PR. Single-branch clone upstream setup now preserves existing fetch mappings. |
| Agent commands and output | Explicit native escapes, stable legacy JSON, additive versioned agent output, schema discovery, exact approval snapshots, and metadata recovery. | Contract tests, native regressions, and independent commit/stack journeys. Arbitrary flag combinations are not exhaustively enumerated. |
| PR/CI stack view | Optional remote view joins review and CI with local relationships, limits lookups, and preserves branches when remote data is unavailable. | Focused behavior tests. Rate-limit and unavailable outcomes use controlled fixtures. Local list stays offline. |
| Provenance and privacy | Local records retain commands, outcomes, revisions, resource URLs, usage reported by providers, and explicit evidence-file references. No prompt/body/source content by default. | Metadata canaries, atomic-write failure checks, publication recovery tests, and actual Windows cross-user storage checks. File references do not verify their contents. |
| Stale dependency guidance | Doctor reports Git support, installed gh attachment capabilities, optional providers, and platform repair steps. Managed Git requires 2.31 before effects. | Actual gh 2.48 identity/preview and unsupported attachment preflight; gh 2.100 live workflows. Git minimum boundaries use fixtures. See [compatibility](COMPATIBILITY.md). |
| Terminal display safety | Managed human output filters terminal commands while retaining styles and Unicode. JSON, piped data, and native escapes retain their values. | Intercepted OSC52 reproduction and output regression checks. Trusted spinner/cursor controls remain separate. |
| Vendor/community comparisons | No runtime requirement can establish historical frustration or another service's reliability. | No such product claim is made. |

The [quality plan](quality/quality-release-plan.md) tracks final release gates. Dated receipts in [verification](verification/) separate source tests, installed packages, live GitHub, terminal behavior, signing, and publication. The initial [test audit](verification/2026-10-14-test-audit.md) removed 104 redundant source cases and one duplicate native case. Later regressions protect defects found during qualification.
